About

Plugin
Thermal RGB (cc-plugin-thermal-rgb)
What it does
Colours your case fans, RAM and motherboard LEDs by CPU temperature, from blue (cool) to red (hot). It reads the same sensor your fan curves use and writes the matching colour through the OpenRGB SDK server. It never changes fan speeds or other CoolerControl settings, and it does not touch devices outside its zones.

How it works
  1. Every second it asks CoolerControl (GET /status) for the CPU temperature.
  2. The value is smoothed with a time-aware moving average.
  3. It is mapped to a colour through the colour stops.
  4. The colour is sent to OpenRGB only when it changed noticeably.
Tested hardware

Written for and tested on one system: MSI MAG B850 TOMAHAWK MAX WIFI (Mystic Light JARGB 1–3), AMD Ryzen 7 9800X3D, two DDR5-6000 modules with ENE RGB controllers, CoolerControl 5.0.1 and OpenRGB 1.0. Other hardware may work through OpenRGB but is untested and needs its own zone list.

Troubleshooting
SymptomUsual cause and fix
HTTP Error 401CoolerControl rejected the token. Create a new one and enter it on the API Settings tab.
HTTP Error 429Rate limiting, usually after repeated 401 errors. Fix the token and wait a moment.
State “waiting”CoolerControl or the OpenRGB server is not reachable; the plugin retries every 10 seconds.
0 zones resolvedThe zone names do not match your OpenRGB devices; see the zones table above and the documentation.
LEDs do not changeLED writes are off, another program writes the same LEDs, or the temperature stays inside one colour band.

CoolerControl access token

The plugin needs an access token to read temperatures from CoolerControl.

  1. In CoolerControl open Access Protection → Access Tokens.
  2. Generate a new token and copy it (cc_…).
  3. Paste it below and save.

The token is stored in credentials.json with restricted permissions (mode 0600) and is never shown again; this page only displays ***. The plugin applies it when it restarts.
